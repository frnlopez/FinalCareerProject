# Tipos de ML

El ML se divide normalmente en dos tipos principales.

El enfoque de aprendizaje supervisado donde el objetivo es aprender una correspondencia entre las entradas "x" y las salidas "y", dado un conjunto etiquetado de pares de entradas y salidas.

Dicho conjunto etiquetado de pares se denomina conjunto de entrenamiento. Las entradas "x" son llamadas características, atributos o covariables, y pueden ser desde datos básicos, como la altura y peso de una persona, hasta datos más complejos, como imágenes, gráficas, ...

Del mismo modo, la forma de la salida o variable de respuesta "y" puede ser cualquiera, pero la mayoría de los métodos asumen que esta salida es una variable categórica o nominal de algún conjunto finito (como masculino o femenino), o que es un escalar de valor real (como el nivel de ingresos). Cuando "y" es categórica, la tarea es de clasificación o reconocimiento de patrones, y cuando es de valor real, la tarea es de regresión.

Algunos de los algoritmos de aprendizaje supervisado más importantes son:

• k-Nearest Neighbors

• Linear Regression

• Logistic Regression

• Support Vector Machines (SVMs)

• Decision Trees and Random Forests

• Neural networks [5]

- El enfoque de aprendizaje no supervisado, donde solo se nos proporcionan entradas y el objetivo es encontrar "patrones interesantes" en los datos. Esto a veces se denomina descubrimiento de conocimientos. Se trata de un problema mucho menos bien definido, ya que no se nos dice qué tipo de patrones debemos buscar y no existe una métrica de error obvia que podamos utilizar (a diferencia del aprendizaje supervisado, en el que podemos comparar nuestra predicción de y para un x dado con el valor observado).

Algunos de los algoritmos de aprendizaje no supervisado más importantes son:

Clustering

K-Means

DBSCAN

Hierarchical Cluster Analysis (HCA)

Detección de anomalías y detección de novedades

One-class SVM

Isolation Forest

Visualización y reducción de dimensionalidad

Principal Component Analysis (PCA)

Kernel PCA

Locally Linear Embedding (LLE)

t-Distributed Stochastic Neighbor Embedding (t-SNE)

Aprendizaje de reglas de asociación

Apriori

Eclat [5]

Existe un tercer tipo de ML, conocido como aprendizaje por refuerzo, que es algo menos utilizado. Este consiste en aprender qué hacer, es decir, cómo relacionar situaciones con acciones, con el finde de maximizar una señal de recompensa numérica. Al alumno no se le dice qué acciones debe realizar, sino que debe descubrir cuáles son las que producen la mayor recompensa probándolas.

Hay otros muchos tipos, como el aprendizaje semi-supervisado (combina conjuntos de entradas y salidas, con solo entradas, para obtener un resultado mejor cuando no hay muchos datos de entrada con su salida correspondiente), o el aprendizaje auto-supervisado (donde el modelo genera sus propios conjuntos de etiquetas, sin supervisión humana).
