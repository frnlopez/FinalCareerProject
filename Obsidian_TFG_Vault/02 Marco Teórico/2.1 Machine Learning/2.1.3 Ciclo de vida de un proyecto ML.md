# Ciclo de vida de un proyecto de ML

Recolección y comprensión de datos

Hay miles de conjuntos de datasets gratis disponibles entre los que elegir, que abarcan todo tipo de ámbitos. Normalmente los vamos a encontrar en formato BBDD.

Para este primer paso los objetivos principales son estudiar los atributos y sus características (sacar el % de valores faltantes, tipo de distribución (gaussiana, uniforme, logarítmica, etc.), …), visualizar lo datos, estudiar las correlaciones entre los atributos, identificar las transformaciones prometedoras que podría querer aplicar.

Limpieza y procesamiento

Lo primero en este paso sería hacer una copia del dataset, para dejar el original intacto, para posteriormente:

Limpieza de datos

- Corregir o eliminar valores atípicos

- Rellenar los valores que faltan o eliminar sus filas (Imputation)

Selección de características (opcional):

- Eliminar los atributos que no aportan información útil para la tarea.

Ingeniería de características, cuando sea apropiado:

- Discretizar las características continuas.

- Descomponer características (por ejemplo, categóricas, fecha/hora, etc.).

- Añadir transformaciones prometedoras de características (por ejemplo, log(x), sqrt(x), x2, etc.).

- Agregar características en nuevas características prometedoras.

Escalado de características:

- Estandarizar o normalizar características.

3. Selección del tipo de modelo

Para seleccionar un modelo lo que se hace es probar con muchos para sacar el que mejor convenga. Para ello, se siguen ciertos pasos:

Entrenar modelos rápidos y sencillos de diferentes categorías ( lineales, bayesians, Random Forests, Neural networks...) utilizando parámetros estándar

Medir y comparar su rendimiento

- Para cada uno utilizaremos validación cruzada (cross-validation) N-fold calculando la media y la desviación estándar en cada uno.

Analizar las variables más significativas para cada algoritmo

Analizar los tipos de errores que cometen los modelos

Realizar una ronda rápida de selección e ingeniería de características

Realizar una o dos iteraciones de los pasos anteriores

Seleccionar los tres modelos más prometedores, dando preferencia a los modelos que cometen diferentes tipos de errores.

4. Entrenamiento del modelo

Ajustar los hiperparámetros utilizando validación cruzada.

Pruebe los métodos de conjuntos (Ensemble methods). La combinación de los modelos con mejores resultados a menudo producirá un mejor rendimiento que ejecutarlos individualmente.

5. Evaluación del rendimiento

Medir su rendimiento en el conjunto de pruebas para estimar el error de generalización [5].
